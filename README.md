# Gym Tracker (PWA)

Una Web App progressiva (PWA) e minimale per il tracciamento degli allenamenti in palestra, progettata per l'uso su dispositivi mobili e integrata con salvataggio locale.

> ⚠️ **Nota:** Questo progetto è un prototipo a scopo dimostrativo e di test, sviluppato con l'ausilio dell'Intelligenza Artificiale.

## Funzionalità
- **Timer di Recupero:** Preset rapidi (1 min, 2 min, 3 min) e timer personalizzabile.
- **Gestione Allenamenti:** Supporto per esercizi di Forza e Cardio con tracciamento delle serie.
- **Filtro Gruppi Muscolari:** Organizzazione rapida degli esercizi per gruppo muscolare.
- **Salvataggio Locale:** I dati e le schede restano salvati nel browser via `localStorage`.
- **Installabile come PWA:** Aggiungibile alla schermata Home del telefono come app nativa.
